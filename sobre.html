Sobre o EduControl

Uma aplicação criada para praticar desenvolvimento web e versionamento.

EC

Nosso objetivo

Desenvolver um pequeno sistema de cadastro de alunos e utilizar corretamente o Git e o GitHub para registrar a evolução do projeto, desde a primeira versão até as melhorias finais.

Funcionalidades

  • ✓ Cadastro de alunos
  • ✓ Consulta e pesquisa
  • ✓ Alteração de registros
  • ✓ Exclusão com confirmação
  • ✓ Armazenamento local no navegador
  • ✓ Interface adaptada para celular
