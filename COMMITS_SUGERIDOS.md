# Plano de 20 commits sugeridos

Faça cada etapa separadamente e registre o commit correspondente depois de realizar a alteração. Não crie commits falsos apenas para atingir a quantidade: cada commit deve representar uma etapa real do trabalho.

1. `chore: cria estrutura inicial do projeto`
2. `docs: adiciona objetivo do projeto ao README`
3. `feat: cria tela de login`
4. `style: estiliza tela de login`
5. `feat: cria menu de navegação`
6. `feat: cria painel inicial`
7. `style: adiciona cards de resumo ao painel`
8. `feat: cria página de cadastro`
9. `feat: valida campos obrigatórios`
10. `feat: salva alunos no LocalStorage`
11. `feat: impede e-mail duplicado`
12. `feat: cria página de listagem`
13. `feat: implementa pesquisa de alunos`
14. `feat: adiciona filtro por sexo`
15. `feat: implementa edição de cadastro`
16. `feat: implementa exclusão com confirmação`
17. `feat: cria página sobre o projeto`
18. `feat: cria formulário de contato demonstrativo`
19. `style: melhora responsividade para celular`
20. `docs: completa instruções de execução no README`

## Comandos iniciais
Abra o terminal do VS Code dentro da pasta do projeto:

```bash
git init
git add .
git commit -m "chore: cria versão inicial do EduControl"
```

Depois, faça mudanças reais e registre commits menores. Para publicar no GitHub, crie um repositório vazio no site do GitHub e siga os comandos que ele mostrar para conectar o repositório local e enviar (`push`) os commits.
